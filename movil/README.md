# movil

App Android del comprador: registro, login y búsqueda de medicamentos por nombre o principio activo, comparando precios entre boticas.

- **Responsable:** Colaborador 2
- **Tecnología:** Kotlin + Jetpack Compose (Android Studio, Gradle)
- **Consume:** API Spring Boot, ver [`docs/API.md`](../docs/API.md). Desde el emulador la API local
  está en `http://10.0.2.2:8080/api`
- **Ramas:** `feature/movil-auth`, `feature/movil-busqueda`
