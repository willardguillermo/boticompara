# H52 · Aprobar una botica

- Historia (Lab06 #58): Como administrador, quiero aprobar una botica, para que quede visible para los usuarios.
- Criterio de aceptación: Al aprobar una botica, sus productos aparecen en la búsqueda del comprador.
- Responsable: Guillermo · Fecha de la prueba: 30/10 y 31/10/2026 · Entorno: admin de Django local + Supabase

## Pasos

1. Aprobar **Botica Nueva Era** desde su ficha (30/10, 14:10).
2. Seleccionar Botica Nueva Era y **Botica Salud Total** (que ya estaba aprobada) y ejecutar la acción **Aprobar boticas seleccionadas** (30/10, 14:17).
3. Consultar en la BD, por botica, los productos activos con stock y los que aparecen en la vista `v_producto_busqueda` (31/10).
4. Probar la vista de búsqueda con la botica de Lucía (Botica Nueva Era, `RECHAZADO`, 2 productos activos con stock), en el SQL Editor de Supabase, dentro de una transacción que se deshace al final (31/10):

```sql
do $$
declare antes int; despues int; lista text;
begin
  select count(*) into antes from v_producto_busqueda where botica_id = 3;
  update botica set estado = 'APROBADO', motivo_rechazo = null where id = 3;
  select count(*), string_agg(nombre_comercial || ' S/ ' || precio, ', ')
    into despues, lista from v_producto_busqueda where botica_id = 3;
  raise exception 'PRUEBA H52 · antes de aprobar: % · después de aprobar: % (%)', antes, despues, lista;
end $$;
```
