# web-usuario

Aplicación web del dueño de botica: registro de su botica (con validación de RUC), estado de aprobación y gestión de su catálogo.

- **Responsable:** Guillermo
- **Tecnología:** React + Vite
- **Puerto local:** 5173 (es el origen permitido por CORS en la API)
- **Consume:** API Spring Boot en `http://localhost:8080/api`, ver [`docs/API.md`](../docs/API.md)
- **Rama:** `feature/web-catalogo`
